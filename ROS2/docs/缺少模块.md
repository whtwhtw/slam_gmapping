# gmapping 模块说明

## 当前状态

gmapping 是一个**SLAM 算法包**，接收激光扫描数据（`/scan`）和里程计数据（TF: `odom→base_link`），然后构建地图。

## 模块完成情况

| 模块 | 状态 | 位置 | 说明 |
|------|------|------|------|
| **gmapping** | ✅ 已完成 | `gmapping/` | SLAM 核心算法 |
| **openslam_gmapping** | ✅ 已完成 | `openslam_gmapping/` | 底层 C++ 库（从源码编译） |
| **laser_driver** | ✅ 已完成 | `laser_driver/` | Camsense X2M 激光雷达驱动 |
| **odometry_publisher** | ✅ 已完成 | `odometry_publisher/` | 模拟里程计（cmd_vel → odom TF） |
| **robot_state_publisher_pkg** | ✅ 已完成 | `robot_state_publisher_pkg/` | 静态 TF 发布（base_link → laser_frame） |

## 两种使用模式

### 模式一：模拟测试（推荐，不需要硬件）

```bash
# 一键启动完整 SLAM 栈
./ros2_docker.sh complete_slam

# 另一个终端：键盘遥控
./ros2_docker.sh shell
source /root/ros2_ws/install/setup.bash
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

数据流：
```
键盘 → /cmd_vel → odometry_publisher → odom TF → gmapping → /map
```

### 模式二：真实机器人（需要硬件）

```bash
# 终端 1：启动激光雷达驱动
ros2 launch laser_driver laser_driver.launch.py port:=/dev/ttyUSB0

# 终端 2：启动底盘驱动（需要你自己提供）
ros2 run your_robot_driver your_driver_node

# 终端 3：启动 gmapping
source /root/ros2_ws/install/setup.bash
ros2 launch gmapping slam_gmapping.launch.py
```

数据流：
```
激光雷达 → laser_driver → /scan ─┐
                                  ├──→ gmapping → /map
编码器/IMU → 底盘驱动 → odom TF ──┘
键盘 → /cmd_vel → 底盘驱动 → 电机
```

## 完整数据流

```
键盘/自动驾驶
      ↓
   /cmd_vel
      ↓
  ┌──────────┐
  │ 底盘驱动  │  ← 你需要自己写或安装
  └────┬─────┘
       ↓
  电机转动/仿真
       ↓
  编码器/IMU
       ↓
  ┌──────────┐
  │ 里程计   │  ← 你需要自己写或安装
  └────┬─────┘
       ↓
  odom TF
       ↓
  ┌──────────┐
  │ gmapping │  ← 本项目（已完成）
  └────┬─────┘
       ↓
    /map 地图
```

## 三种使用方案

### 方案 A：实体扫地机器人

```
真实硬件:
  激光雷达驱动    → 发布 /scan
  编码器/IMU      → 发布 odom TF
  底盘驱动        ← 订阅 /cmd_vel

配合 gmapping 即可建图
```

**适用场景**：有真实的扫地机器人硬件，需要将 gmapping 部署到机器人上。

### 方案 B：Gazebo 模拟器（推荐测试）

```bash
# 安装 turtlebot3 仿真
apt-get install ros-humble-turtlebot3-*
export TURTLEBOT3_MODEL=burger
ros2 launch turtlebot3_gazebo turtlebot3_world.launch.py
```

**优点**：
- 不需要硬件
- 纯软件环境，随时测试
- Gazebo 自动提供 `/scan` 和 `odom` 数据

**配合 gmapping**：

```bash
# 终端 1：启动仿真
ros2 launch turtlebot3_gazebo turtlebot3_world.launch.py

# 终端 2：启动 gmapping
source /root/ros2_ws/install/setup.bash
ros2 launch gmapping slam_gmapping.launch.py \
  scan_topic:=/scan \
  base_frame:=base_footprint \
  odom_frame:=odom

# 终端 3：键盘遥控
ros2 run teleop_twist_keyboard teleop_twist_keyboard
```

### 方案 C：rosbag 回放

```bash
# 使用录制好的 bag 文件测试 gmapping
source /root/ros2_ws/install/setup.bash
ros2 run gmapping slam_gmapping_replay --bag_filename /path/to/bag.db3
```

**适用场景**：已有录制好的传感器数据，想验证 gmapping 算法效果。

## 如何获取 bag 文件

```bash
# 录制命令
ros2 bag record -o my_scan_data /scan /tf /tf_static

# 回放命令
ros2 bag play my_scan_data
```
