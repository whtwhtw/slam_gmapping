# ROS2 gmapping 项目架构与能力说明

## 一、项目概述

本项目是将原始 ROS1 的 `gmapping` 包迁移到 ROS2 Humble 版本，实现了 2D 激光 SLAM 建图功能。

在此基础上，新增了**激光雷达驱动**、**模拟里程计发布**、**机器人状态发布**等模块，形成了可独立运行（无需真实硬件）的完整 SLAM 系统。

## 三、Topic 与服务

### gmapping 节点

**订阅：**

| Topic | 类型 | 说明 |
|-------|------|------|
| `scan` | `sensor_msgs/msg/LaserScan` | 2D 激光雷达扫描数据 |
| TF: `odom` → `base_link` | 变换 | 通过 tf2_ros::Buffer 获取里程计位姿 |

**发布：**

| Topic | 类型 | 说明 |
|-------|------|------|
| `map` | `nav_msgs/msg/OccupancyGrid` | 2D 占据栅格地图 |
| `map_metadata` | `nav_msgs/msg/MapMetaData` | 地图元数据 |
| `entropy` | `std_msgs/msg/Float64` | 粒子滤波熵（不确定性） |
| TF: `map` → `odom` | 变换 | SLAM 校正变换 |

**服务：**

| Service | 类型 | 说明 |
|---------|------|------|
| `dynamic_map` | `nav_msgs/srv/GetMap` | 返回当前地图 |

### laser_driver 节点

**发布：**

| Topic | 类型 | 说明 |
|-------|------|------|
| `scan` | `sensor_msgs/msg/LaserScan` | 激光雷达扫描数据 |

### odometry_publisher 节点

**订阅：**

| Topic | 类型 | 说明 |
|-------|------|------|
| `cmd_vel` | `geometry_msgs/msg/Twist` | 机器人速度指令 |

| Topic | 类型 | 说明 |
|-------|------|------|
| `odom` | `nav_msgs/msg/Odometry` | 里程计消息 |

## 四、TF 坐标帧要求

```
map → odom → base_link → laser_frame
```

| 坐标帧 | 发布者 | 说明 |
|--------|--------|------|
| `map` → `odom` | **gmapping** | SLAM 算法计算的校正变换 |
| `odom` → `base_link` | `odometry_publisher` 或真实里程计 | 模拟/真实里程计 |
| `base_link` → `laser_frame` | `robot_state_publisher` | 激光雷达安装位置（URDF） |

**模拟模式（无需硬件）：**
- `odometry_publisher` 订阅 `/cmd_vel`，积分得到位姿，发布 `odom→base_link`
- `robot_state_publisher` 根据 URDF 发布 `base_link→laser_frame`

**真实机器人模式：**
- 真实底盘驱动发布 `odom→base_link`
- 激光雷达驱动发布 `/scan`

## 五、核心算法

### GridFastSLAM (GMapping)

结合三种技术：

1. **Rao-Blackwellized 粒子滤波器** — 每个粒子代表一条机器人轨迹
2. **ICP 扫描匹配** — 将新激光扫描与已有地图对齐，修正里程计漂移
3. **占据栅格地图构建** — 输出 2D 栅格地图，默认分辨率 5cm/像素

### 更新触发条件

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `linearUpdate` | 1.0 米 | 移动超过此距离才处理新扫描 |
| `angularUpdate` | 0.5 弧度 | 旋转超过此角度才处理新扫描 |
| `temporalUpdate` | -1.0（禁用） | 每隔此时间强制更新 |
| `map_update_interval` | 5.0 秒 | 地图重新计算和发布间隔 |

## 六、能力边界

### ✅ gmapping 能做的

| 能力 | 说明 |
|------|------|
| 2D 建图 | 从激光雷达+里程计构建占据栅格地图 |
| 自身定位 | 通过粒子滤波器估计机器人在地图中的位姿 |
| TF 发布 | 发布 `map`→`odom` 变换，供导航栈使用 |

### ❌ gmapping 不能做的

| 能力 | 需要什么额外模块 |
|------|-----------------|
| 机器人运动控制 | `robot_driver` / `ros2_control` |
| 路径规划 | `nav2_controller` (Nav2) |
| 避障 | `nav2_dwb_controller` (Nav2) |
| 自主探索建图 | `explore_lite` 或 Nav2 exploration |
| 全局导航 | `nav2_planner` + `nav2_bt_navigator` |

**gmapping 只做感知层面的事——建图和定位，不产生任何运动控制指令。**

## 八、ROS1 → ROS2 主要变更

### 构建系统

| ROS1 | ROS2 |
|------|------|
| catkin | ament_cmake |
| `find_package(catkin REQUIRED ...)` | `find_package(ament_cmake REQUIRED)` + 逐个 `find_package` |

### 依赖包

| ROS1 | ROS2 |
|------|------|
| `roscpp` | `rclcpp` |
| `tf` | `tf2` + `tf2_ros` + `tf2_geometry_msgs` |
| `nodelet` | `rclcpp_components` |
| `rosbag_storage` | `rosbag2_cpp` + `rosbag2_storage` |
| `rostest` | `ament_lint_auto` + `ament_lint_common` |

### C++ API

| ROS1 | ROS2 |
|------|------|
| `ros::NodeHandle` | `rclcpp::Node` (继承) |
| `ros::Publisher` | `rclcpp::Publisher<T>` |
| `tf::TransformListener` | `tf2_ros::Buffer` + `tf2_ros::TransformListener` |
| `tf::MessageFilter` | `tf2_ros::MessageFilter` |
| `boost::thread` | `std::thread` |
| `boost::mutex` | `std::mutex` |
| `boost::shared_ptr` | `std::shared_ptr` |

### Launch 文件

| ROS1 | ROS2 |
|------|------|
| XML (`.launch`) | Python (`.launch.py`) |
| `<node pkg="..." type="..." name="...">` | `Node(package='...', executable='...', name='...')` |

## 九、新增模块说明

### 1. laser_driver（激光雷达驱动）

| 属性 | 值 |
|------|------|
| SDK 来源 | `/media/wht/I/视频教程/自动驾驶/激光雷达/SDK_V3.0` |
| 雷达型号 | Camsense X2M |
| 通信方式 | 串口（`/dev/ttyUSB0`） |
| 数据回调 | 点云回调 → 排序 → 发布 `sensor_msgs/LaserScan` |

**参数：**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `port` | `/dev/ttyUSB0` | 串口设备路径 |
| `baud` | `115200` | 波特率 |
| `model` | `X2M` | 雷达型号 |
| `scan_topic` | `scan` | 发布的话题名 |
| `frame_id` | `laser_frame` | 坐标系 ID |
| `min_range` | `0.05` | 最小检测距离（米） |
| `max_range` | `16.0` | 最大检测距离（米） |

**启动：**

```bash
ros2 launch laser_driver laser_driver.launch.py port:=/dev/ttyUSB0
```

### 2. odometry_publisher（模拟里程计）

订阅 `/cmd_vel` 速度指令，通过积分计算位姿，发布 `odom→base_link` TF 变换。

**参数：**

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `odom_frame` | `odom` | 里程计坐标系 |
| `base_frame` | `base_link` | 机器人基坐标系 |
| `publish_rate` | `30.0` | 发布频率（Hz） |

**数据流：**

```
/cmd_vel (Twist) → 积分 → odom TF + /odom (Odometry)
```

**启动：**

```bash
ros2 run odometry_publisher odometry_publisher
```

### 3. robot_state_publisher_pkg（机器人状态发布）

根据简单的 URDF 文件发布静态 TF 变换（`base_link` → `laser_frame`）。

**URDF 结构：**

```xml
base_link ──[0, 0, 0.1]──→ laser_frame
```

**启动：**

```bash
ros2 launch robot_state_publisher_pkg robot_state_publisher.launch.py
```

### 4. complete_slam.launch.py（一键启动）

同时启动以上三个模块 + gmapping，无需任何硬件即可测试 SLAM 功能。

```bash
./ros2_docker.sh complete_slam
```

这会启动：
1. `robot_state_publisher` — 发布 `base_link→laser_frame` TF
2. `odometry_publisher` — 订阅 `/cmd_vel`，发布 `odom→base_link` TF
3. `gmapping` — 接收 `/scan` + 里程计，构建地图

配合 `teleop_twist_keyboard` 即可遥控建图。

详细对照见 `../README.md`。
